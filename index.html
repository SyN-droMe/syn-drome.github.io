Selected work

Emulsion

try it → view repo →

An interactive map of 3,222 recipes where any two dishes can be routed together, either by what they're made of or by how they're cooked. A slider trades TF-IDF ingredient similarity against sentence-embedding technique similarity, and routes were measured for smoothness rather than assumed.

3,222 recipes · 1,055 canonical ingredients
98% of dish pairs routable
Python · all-MiniLM-L6-v2 · PCA + UMAP · static data, no backend

Bulkhead

view repo →

A tool-calling harness for LLM agents built around one question: when a tool breaks, does it recover, fail honestly, or fail silently? Proved against six injected failure modes instead of demoing the happy path.

5 of 7 scenarios recovered or failed honestly
0 uncaught crashes or hangs
Python · Groq tool-calling · daemon-thread timeout enforcement

ShrinkWrap

view repo →

A drop-in wrapper that intercepts every LLM call and runs it through a measured token-reduction pipeline (caching, adaptive limits, compression), with output quality checked against the baseline rather than assumed.

26.5% lower total tokens
27.9% lower cost
Python · Anthropic SDK · AWS Bedrock
